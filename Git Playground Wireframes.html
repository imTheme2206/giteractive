The core mechanic: visual gesture → real git command. Each move narrates itself and rewrites the graph.

click

Add a commit

A pulsing ghost + node always floats next to HEAD. Click it to spawn a commit and march the branch pointer forward.

$git commit -m "feat: new commit"
drag

Cherry-pick a commit

Grab a single commit off feature and drop it on main's tip. A dashed duplicate c5' previews where it lands.

$git cherry-pick c5
drag

Rebase a branch

Drag the whole feature label onto main's tip. Its commits slide over onto c3 — history visibly rewriting.

$git rebase main
LEGEND main feature HEAD previewed / new

The terminal banner mirrors the mouse in real time, then commits the action to a running session log.
